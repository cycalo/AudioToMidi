# BPM Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Auto-detect BPM from the drum WAV, expose an editable BPM control, and stamp that tempo into exported MIDI so DAW playback speed matches the track.

**Architecture:** New `pipeline/tempo.py` estimates BPM via `librosa.beat.beat_track`. `AnalysisState` carries `detected_bpm`. Main window seeds a `QDoubleSpinBox` and passes it to `export_midi` → existing `write_midi(..., tempo=)`.

**Tech Stack:** Python, librosa, pretty_midi, PySide6, pytest

**Spec:** `docs/superpowers/specs/2026-07-23-bpm-sync-design.md`

**Status:** Implemented (2026-07-23). Full suite: 118 passed.

## Global Constraints

- No quantization of note times
- BPM range 40.0–240.0; fallback 120.0 on detection failure
- Tempo detection must not fail Convert
- Preserve user BPM override across sensitivity re-runs
- CLI auto-detect out of scope
